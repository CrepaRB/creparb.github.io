坦克大战 游戏说明书

---

第一节：游戏规则

欢迎来到像素战场！你操控一辆绿色坦克，在由木板与石砖构成的迷宫中与红色敌军坦克作战。

基本目标

消灭当前地图上的所有敌方坦克即可获胜。若有多张地图，游戏会自动切换到下一张地图，全部通关后迎来最终胜利。

操作方法

· 移动：WASD 或 方向键
· 炮台转向：YUIHJKNM, 或 小键盘
· 开火：J 或 5 键
· 旋转炮台：E / Q（使用四向箭头控制键移动时也可按 W开火）
· 暂停：ESC

核心机制

· 坦克由“车身”和“炮台”两部分组成，两者转向相对，但未操作炮台时，炮台将跟随车身转向。
· 车身移动方向与车头朝向密切相关，目标方向与车头夹角较小时会边移动边转向，否则会原地转向。
· 炮弹可以反弹一定次数，木板会被削减耐久，直到摧毁，石砖则永远坚固。
· 战场上随机出现四种道具：回血、激光、护盾、超频。

胜利条件

摧毁当前地图的所有敌人。如果你被摧毁，游戏结束。

游戏中还有更多可调节的细节，比如坦克灵敏度、炮弹速度、弹跳次数、生命值等，这些都可以在“设置”界面中自行探索，找到最适合你的战斗风格。

第二节：高级功能

更换游戏背景

游戏支持自定义背景装饰。背景实际上是一个完整的 HTML 文件（包括样式和脚本），会被注入到游戏画面的背景层中。

1. 打开 设置 → 界面设置
2. 点击 “导出” 按钮，可以将当前背景保存为 HTML 文件
3. 点击 “替换” 按钮，选择一个 HTML 文件

系统会弹出警告，确认后该文件的 <body> 部分将成为新的游戏背景。请尽量使用内联样式以保证显示效果。理论上你可以通过这种方式注入任意 JavaScript 代码，游戏不禁止这种行为，但请务必确认文件来源安全。

编辑地图

地图使用多行字符串定义，位于 设置 → 地图配置 中。

地图符号含义

符号 含义
□ 空地
■ 木板障碍（有耐久度）
■+ 石砖障碍（不可摧毁）
☆ 玩家备选出生点（多个时随机选择）
◆ 敌人出生点（每个生成一个敌人）

编写规则

· 边缘会自动增加一圈石砖，无需手动添加。
· 使用空行分隔多张地图，游戏会依次切换。
· 单张地图内，所有行的砖块数量必须一致，并至少包含一个我方备选出生点与敌方出生点，否则无法开始游戏。
· 游戏运行期间地图编辑器会被锁定。

修改地图后点击 “验证全部地图” 即可检查格式是否正确，尝试保存设置或开始游戏时，游戏也会自行检查。

游戏切换地图时会进行一系列判定：
* 如果两张图尺寸一致，则游戏不会重置您的位置，但如果您的位置与新地图中的物件重叠了，游戏还是会重置您的位置。
* 如果两张图尺寸不一致，游戏总会重置您的位置。

第三节：隐藏功能

覆写默认配置

游戏支持通过配置文件完全覆写内置默认值。

1. 在设置中调整好所有选项
2. 点击 “导出设置”，会生成一个 JSON 文件
3. 将该文件重命名为 default 或 Default（不带扩展名或带 .json 均可）
4. 回到游戏主菜单，点击 “导入设置” 并选择该文件

系统会弹出警告，告知你将生成一个默认配置被覆写的新游戏文件。确认后，会下载一个全新的 HTML 文件，其中内置的默认配置已经被你提供的设置替换。

自定义背景音乐

背景音乐使用简谱系统，可以在导出的配置文件中直接编辑。

配置格式

```json
"musicPattern": [
    [调式编号, BPM],
    "简谱序列"
]
```

调式编号对照表

编号 调式
-1 F大调
0 B大调
1 C大调
2 D大调
3 A大调
4 E大调
5 B大调
6 F#大调
7 C#大调

简谱数字与音高的关系

· 1~7：中央八度内的音级
· 8~14：高八度（8=高音1，9=高音2……）
· 15~21：更高八度
· 0~-6：低八度（0=低音7，-1=低音6……）
· -7~-13：更低八度

音符持续时间

使用 音高_持续拍数 的格式。例如：

```
1_2  表示音高1持续2拍
3    表示音高3，沿用上一个音符的持续拍数
5_0.5 表示音高5持续半拍
```

示例

```json
"musicPattern": [[1, 120], "1_2 3 5 3 6_2 5 4 3 4_2 3 5 2 1_4"]
```

这表示：C大调，120 BPM，旋律为 C E G E A G F E F E G D C（长音）。

注意事项

· 音高范围最终会被限制在 MIDI 0~127 之间
· 支持负数音高
· 无法解析的非数字符号会被视为休止符
· 修改音乐后需要重新导入配置或在源码中修改默认值

音乐系统采用 8-bit 方波音色，旋律会自动循环播放。祝你创作出属于自己的战场旋律！
