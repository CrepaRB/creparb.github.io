进阶场景

HTML / CSS

~90%
了解网页需要包含的内容要素，能够编写较复杂页面，能够独立维护复杂的大型样式表。
例如，本页面中包含以下设计：
  • 具有视差效果、入场动画的简约线框，可通过类注册表设计迅速配置。
  • 精心设计运动规律，营造扩散入场效果的模糊背景。
  • 动态样式、自动向上吸附的顶栏。

  • 响应式布局，适配不同屏幕尺寸，部分元素在不同布局中有截然不同的表现。

  • 优雅的优化设计，电脑端调整页面大小时自动暂停一切由JS驱动的动态内容，降低性能负担。（不过嘛……开场动态范围的模糊确实有点太考验设备了）。
